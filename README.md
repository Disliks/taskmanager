Task Manager
Мобильное приложение для управления задачами и заявками для диспетчеров, менеджеров и технических специалистов.

Функционал
Создание, редактирование и просмотр задач

Фильтрация по статусу (Новые/В работе/Выполнены)

Фильтрация по приоритету (Высокий/Средний/Низкий)

Поиск по названию, адресу и технику

Авторизация с разными ролями

Технологии
Java

Android SDK (min API 21)

SharedPreferences для хранения данных

RecyclerView, CardView, Material Design

Установка
Клонировать репозиторий

Открыть в Android Studio

Запустить на устройстве или эмуляторе

Тестовые учетные записи
Диспетчер: dispatcher / 123

Менеджер: manager / 123

Техник: technician / 123

Структура проекта
activities/ - экраны приложения

adapters/ - адаптеры для RecyclerView

models/ - модели данных

utils/ - вспомогательные классы

Цвета статусов
Новая - синий

В работе - оранжевый

Выполнена - зеленый

Цвета приоритетов
Высокий - красный

Средний - оранжевый

Низкий - зеленый
